## Projects

### [AI Profile Builder](https://github.com/spkrause-maker/ai-profile-builder) · [▶ Try it](https://claude.ai/artifact/RSAgJpLEWzWwSz1Qe97o3x)
Supply is the hard side of a two-sided marketplace, and the profile is where providers drop off. This conversational onboarding prototype turns a handyman's answers to eight plain questions into a polished, shareable profile and a review-request text. It ships with the [launch strategy](https://github.com/spkrause-maker/ai-profile-builder/blob/main/docs/local-ai-commerce-strategy-deck.pdf) it was built for: a case study on launching home services on a hyperlocal news platform.

`Product strategy` · `Marketplace cold-start` · `Prototyping` · `React`

### [Hero Academy](https://github.com/spkrause-maker/hero-academy) · [▶ Play it](https://spkrause-maker.github.io/hero-academy/)
A research-based multiplication game I built for my third grader. Each superhero team's "power" is a real mental-math strategy, and the mechanics (retrieval practice, spaced review, mixed practice) come straight from the learning-science research, which is [documented in the repo](https://github.com/spkrause-maker/hero-academy/blob/main/docs/RESEARCH.md).

`JavaScript` · `Learning design` · `Research-led product`
